II. PHẠM VI CÔNG VIỆC CỦA DEV BACKEND / CMS (LƯU Ý QUAN TRỌNG)
--------------------------------------------------------------------------------
1. Bạn phụ trách 100% cả Backend, Database Schema LẪN Giao diện quản trị CMS (/admin):
   - Dự án sử dụng Payload CMS 3.x chạy chung trong Next.js 16.2+ tại đường dẫn `/admin`.
   - Khi bạn khai báo xong các file Collection (`src/collections/*.ts`) và Global
     (`src/globals/*.ts`) theo đúng `02-CMS-BE.md`, Payload CMS sẽ TỰ ĐỘNG SINH RA
     100% giao diện CMS tại `/admin` (đăng nhập, bảng danh sách, bộ lọc, trình
     soạn thảo Lexical, upload ảnh, duyệt/từ chối bài gửi...).
2. Bạn KHÔNG cần viết REST API CRUD cho các trang nội dung:
   - Đội FE sẽ đọc dữ liệu trực tiếp qua Payload Local API.
   - Bạn chỉ cần viết đúng **5 Custom Endpoints** tại `src/endpoints/` (theo mục 7.2
     và 8.2 của `02-CMS-BE.md`) và 1 route nội bộ `/api/internal/revalidate`.
3. Đầu ra bàn giao cho Dev FE:
   - Sau khi tạo/cập nhật xong các collections và globals, bạn chạy lệnh:
     `pnpm payload generate:types`
   - Commit file `src/payload-types.ts` lên nhánh chung để Dev FE lấy kiểu dữ liệu
     TypeScript sử dụng.
